# Cổng Thông Tin Chi Đoàn & Tập Thể Lớp 11A10 - THPT Cát Tiên

Trang web thông tin nội bộ của tập thể lớp 11A10, trường THPT Cát Tiên (Lâm Đồng) cho năm học 2026 - 2027.

## Chức năng chính
- **Thời khóa biểu**: Xem lịch học buổi sáng và chiều, trích xuất và hiển thị thời khóa biểu tự động.
- **Thành viên & Ban cán sự**: Quản lý danh sách học sinh và thông tin liên lạc ban cán sự.
- **Bản tin & Thông báo**: Cập nhật thông báo học tập, phong trào đoàn trường.
- **Tài liệu & Thư viện**: Lưu trữ tài liệu ôn tập và bài giảng các bộ môn.
- **Bốc thăm & Trò chơi**: Hỗ trợ bốc thăm ngẫu nhiên học sinh phát biểu, trực nhật.

## Công nghệ sử dụng
- React 18 + Vite + TypeScript
- Tailwind CSS
- Supabase (Xác thực và cơ sở dữ liệu)
- Lucide React & Framer Motion

## Cài đặt & Chạy dự án
```bash
# Cài đặt thư viện
npm install

# Khởi chạy môi trường phát triển
npm run dev

# Đóng gói sản phẩm
npm run build
```
